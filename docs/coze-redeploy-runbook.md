# Coze Redeploy Runbook

这份文档用于以后重新在扣子（Coze）创建、部署、上架“简历证据链”技能。它假设 GitHub 仓库和发行包已经准备好，但扣子后台可能需要从头再操作一次。

## 0. 本地准备

先在仓库根目录运行：

```bash
python3 tools/build_release.py --version 0.2.0
python3 tools/check_launch_ready.py
```

如果刚刚重新生成过发行包，建议按上面的顺序依次运行，不要把构建和检查并行执行，因为构建脚本会清理并重建 `dist/` 目录。

如果还没替换真实微信赞赏码，`check_launch_ready.py` 会出现一个 placeholder warning，这是预期警告，不影响扣子上架材料准备。

本地发行目录：

```text
dist/high-density-resume-v0.2.0/
```

关键文件：

```text
high-density-resume-skill-v0.2.0.zip
coze-store-listing.zh.md
services.md
monetization.md
assets/coze-case-low-material.svg
assets/coze-case-formula-student.svg
assets/coze-case-ai-review.svg
```

## 1. 创建或重建技能

推荐方式：

1. 打开扣子技能 / 扣子编程入口。
2. 创建新技能项目。
3. 使用下面的开发提示词，让扣子生成 Skill 项目。
4. 生成后检查 `SKILL.md`、`.coze`、部署页。

开发提示词可直接使用：

```text
请创建一个可发布到扣子技能商店的中文 AI 技能，名称为「简历证据链」。

定位：帮助大学生、实习求职者、转行者把零散经历整理成高密度、真实、HR 友好、经得起面试追问的简历内容。

核心理念：简历不是经历列表，而是个人能力结构的压缩证据链；每一句都要回答“我是谁、我能做什么、我和别人有什么不同”。

请根据以下项目文件设计技能行为：
- SKILL.md 需要包含输入路由、证据单元、低素材挖掘、面试风险检查、失败模式、检查点和风险黑名单。
- 支持场景：从零写简历、改写单段经历、审查已有简历、面试追问风险检查、审查另一个 AI 的修改建议。
- 不允许编造事实，不允许把参与写成主导，不允许把基于模板修改写成原创设计，不允许写医疗治疗或治愈承诺。
- 对没实习、没竞赛、没项目的学生，要从课程、社团微任务、帮助他人、AI 辅助学习、非典型技能中挖掘真实证据。
- 对中医针灸等健康相关经历，只能作为个人技能、服务意识、团队融入和信任建立信号表达，不能写治疗、治愈、诊断或医疗效果。

开场白：
把你的简历、某段经历，或者目标岗位发给我。我不会一上来帮你套模板，而是先帮你把经历拆成真实、可验证、HR 能看懂的证据链。

快捷入口：
- 从零开始写简历
- 改写一段经历
- 审查已有简历
- 面试追问风险检查
- 审查另一个 AI 的修改建议

请生成可预览、可部署、后续可上架技能商店的项目。不要夸大能力，不要自动发布。
```

如果扣子支持上传 Skill 包，优先上传：

```text
dist/high-density-resume-v0.2.0/high-density-resume-skill-v0.2.0.zip
```

如果上次项目状态已经乱了，直接按“从零重来”处理：

1. 新建一个空技能项目，不复用旧项目。
2. 先用开发提示词生成基础项目。
3. 再上传或复制 `SKILL.md`、`references/`、`test-prompts.json` 的内容。
4. 保存并提交一次版本。
5. 先在预览对话里跑 3 个案例，再部署。
6. 部署成功后才进入商店上架和商户设置。

## 2. 常见部署错误

### 错误：skill name not found in .coze file

现象：

```text
PackageRepo failed ... skill name not found in .coze file
```

处理：

1. 检查项目根目录是否有 `.coze`。
2. 如果没有，让扣子“一键修复”或手动创建。
3. `.coze` 至少应声明技能 id/name。上次可工作的最小方向类似：

```json
{
  "id": "resume-coach",
  "name": "resume-coach"
}
```

4. 修改后提交版本，再重新部署。

### 错误：已变更但未提交

现象：部署前提示有未提交代码。

处理：

1. 去源代码管理。
2. 填提交信息，例如：

```text
chore: prepare skill deployment
```

3. 点击提交。
4. 回到部署页重新部署。

### 错误：部署成功但找不到商店收益入口

部署成功只代表技能能运行，不代表已经赚钱。

下一步还需要：

- 进入技能商店上架流程。
- 填写分类、简介、详细介绍和案例。
- 开通商户或收款能力。
- 设置免费、付费或订阅模式。
- 等待平台审核。

## 3. 上架字段

直接复制：

```text
dist/high-density-resume-v0.2.0/coze-store-listing.zh.md
```

推荐字段：

```text
技能名称：简历证据链
分类：办公与效率
一句话简介：帮普通大学生把零散经历写成真实、可追问的简历
```

备选分类：

```text
专业咨询 / 教育科研 / 创作与写作
```

## 4. 三个案例

上架前要在扣子对话区真实跑完 3 个案例：

1. 低素材大学生简历挖掘
2. 方程式赛车经历高密度改写
3. 审查另一个 AI 的修改建议

案例脚本在：

```text
packaging/coze-store-listing.zh.md
```

可用封面在：

```text
assets/coze-case-low-material.svg
assets/coze-case-formula-student.svg
assets/coze-case-ai-review.svg
```

## 5. 需要用户确认的动作

以下动作不要由自动化直接完成，必须当场确认：

- 公开发布 / 上架技能商店。
- 开通商户、绑定收款、设置付费价格。
- 上传含个人信息的案例截图。
- 提交审核。
- 删除或覆盖已有线上技能。

## 6. 上架前最终检查

- [ ] 技能能部署成功。
- [ ] 能在扣子对话区打开并触发技能。
- [ ] 三个案例都完整跑完。
- [ ] 案例中没有真实手机号、邮箱、微信号、身份证、家庭住址。
- [ ] 描述中没有“保证 offer”“保证 ATS 通过”“保证赚钱”。
- [ ] 付费设置已由用户确认。
- [ ] 商户/收款入口已按平台要求开通。
