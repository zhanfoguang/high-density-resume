# 简历高密度评分表

用这个评分表快速判断简历是否足够真实、有识别度、对齐岗位、容易被 HR 搜到，并且经得起面试追问。总分 18 分，建议修改到 14 分以上再投递。

## 评分维度

| 维度 | 0 分 | 1 分 | 2 分 | 3 分 |
| --- | --- | --- | --- | --- |
| 真实性 | 夸大明显，主导/参与边界混乱 | 有真实经历，但措辞偏满 | 大多数表述边界清楚 | 每条核心经历都能对应真实动作和参与层级 |
| 个人识别度 | 像通用模板，看不出是谁 | 有少量差异点但被埋没 | 能看出个人特点 | 前 1/3 就能记住这个人的能力结构或行为模式 |
| 求职方向匹配 | 求职意向和正文脱节 | 有方向，但核心证据靠后 | 方向与多数经历相关 | 求职意向、黄金位经历和技能关键词形成同一条主线 |
| HR 搜索率 | 缺少目标岗位关键词 | 有关键词但泛或堆砌 | 关键词基本真实自然 | 岗位关键词真实、自然、分布在经历和技能中，且能被机器检索 |
| 面试可追问性 | 多数内容答不上来 | 能讲背景，细节薄 | 核心项目能讲清楚 | 每个强词、工具、数字都能解释来源和过程 |
| 结构扫读性 | 信息堆叠，难扫读 | 有分区但重点不清 | 重点基本清楚 | 模板保守清晰，黄金位、分类、行距和标题都服务扫读 |

## 解释

### 0-7 分

简历仍像经历列表或 AI 套话。先不要继续修辞，回到证据单元表，把每段经历拆成真实动作、工具/方法和结果。

### 8-13 分

已经有真实信息，但主线、关键词或追问风险还不稳定。优先处理求职意向、黄金位经历和面试答不上来的强词。

### 14-18 分

可以进入投递版本。最后做一次人工带读或模拟面试，删除答不上来的细节。

## 快速自查

- [ ] 求职意向和第一段核心经历互相呼应。
- [ ] 最强经历放在简历前 1/3。
- [ ] 每条核心经历至少包含动作、工具/方法、结果中的两个。
- [ ] 没有把参与写成主导。
- [ ] 没有无法解释的数据、工具名或强动词。
- [ ] 目标岗位关键词真实出现，没有硬堆。
- [ ] 关键词不仅出现在技能栏，也出现在真实经历里。
- [ ] 简历模板保守、清晰、机器可读，没有把核心信息放进图片或复杂排版。
- [ ] 每段核心经历能回答“我能给企业带来什么价值”。
- [ ] 个人差异点没有被删成通用模板。
- [ ] 删除了“具备较强能力”“学习了”“锻炼了”等无证据表达。

## HR 搜索率提醒

关键词要来自真实经历，不要为了搜索率硬塞。更好的方式是把关键词放进证据句里：

弱：

```text
熟悉智能制造、PLC、AI 工具。
```

稳：

```text
主修电气控制与 PLC 应用，参与整车电器线路布局与传感器调试，并使用 Codex 整理赛事规则、辅助限时答题策略优化。
```

## 企业价值提醒

简历不只是证明“我做过”，还要证明“我对岗位有什么价值”。检查每条核心经历时问：

```text
这件事能证明我能为企业节省时间、降低成本、完成基础工作、解决问题、支持团队，还是带来稀缺组合能力？
```

如果回答不上来，这条经历需要继续挖动作、对象、结果和岗位关联。
