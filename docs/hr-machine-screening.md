# HR 与机器筛选友好规则

高密度简历不等于花哨简历。识别度来自内容，不来自模板创新。

简历通常要先过两关：

1. 机器或系统筛选：能不能识别到岗位关键词。
2. HR 快速扫读：5-10 秒内能不能看出候选人的能力、价值和差异点。

## 1. 模板不要过度创新

模板要保守、清晰、机器可读、HR 熟悉。

建议：

- 使用常规分区：基本信息、求职意向、教育背景、实习/实践经历、项目经历、校园经历、技能、证书。
- 少用复杂表格、文本框、图标、进度条、双栏花式排版。
- 不把核心信息放进图片。
- 文件导出为 PDF 前，确认文字可以被复制和搜索。
- 标题清晰，日期和角色位置稳定。

原则：

```text
模板负责降低阅读成本，内容负责建立识别度。
```

## 2. 给机器喂真实关键词

如果岗位 JD 里反复出现某些词，简历里要真实、自然地出现这些词。

例如智能制造方向：

- 智能制造
- 自动化
- 电气控制
- PLC
- PCB
- Altium Designer / 立创 EDA
- UG / CAD
- 传感器
- 设备调试
- 工业电控
- Python
- AI Agent

关键词不要只堆在技能栏，更应该出现在经历证据里。

弱：

```text
熟悉 PLC、PCB、AI 工具、智能制造。
```

稳：

```text
参与整车电器线路布局与传感器调试，使用 Altium Designer / 立创 EDA 修改 PCB，并使用 Codex 整理赛事规则、辅助限时答题策略优化。
```

## 3. 简历是干出来的，不是写出来的

没有事实，再好的 AI 也只能写出空话。

如果用户经历很少，下一步不是继续润色，而是去做能留下证据的事：

- 完成一个课程设计并留下报告。
- 把课堂实验整理成可复用清单。
- 做一个小工具并部署或开源。
- 参加一次活动并承担具体任务。
- 用 AI 工具解决一个真实问题，并记录输入、过程、验证和输出。

简历里的强表达，应该来自已经发生的动作和交付物。

## 4. 企业价值视角

写简历时要反复问：

```text
我对这个岗位、这个企业有什么价值？
```

价值可以来自：

- 专业能力：能做技术、工程、设计、调试、分析。
- 执行能力：能把任务推进到交付。
- 学习能力：能快速进入陌生领域。
- 协作能力：能融入团队、帮助别人、承担现场工作。
- 成本价值：作为实习生，能承担基础工作、降低团队人力压力。
- 稀缺性：有别人不常见但真实可解释的组合能力。

简历表达可以用这个公式检查：

```text
我做过什么 + 能给岗位带来什么价值 + 为什么我有一点稀缺性
```

## 5. 活动经历不要只写参加

“参加过很多活动”不等于有能力。

每个活动至少说清：

- 你承担了什么任务？
- 你服务了谁？
- 你解决了什么问题？
- 你留下了什么结果？
- 你增长的能力是否能从事实中看出来？

弱：

```text
参加多场校园活动，提升组织能力。
```

稳：

```text
参与校内社会实践活动组织，负责报名信息整理、现场流程协助与物资分发，服务 50+ 参与者并保障活动按计划推进。
```

## 6. HR 扫读检查

把自己当成 HR，5 秒钟扫一遍简历，问：

- 我能不能看出他投什么岗位？
- 我能不能看到岗位关键词？
- 我能不能看到最硬的一条证据？
- 我能不能看出他能给企业带来什么价值？
- 我能不能记住一个和别人不同的点？

如果答案是否定的，优先改求职意向、黄金位经历和关键词分布。
