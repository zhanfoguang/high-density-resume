# Suggested Pricing

这份建议用于把开源项目转成小额、可交付、低风险的服务。价格不是承诺收入，也不是固定报价；真正收费前应根据时间、隐私要求、材料复杂度和沟通成本调整。

## 定价原则

- 开源内容免费，深度追问和私密带读收费。
- 先做小单，验证用户是否真的愿意为“真实、可追问、能落地”的简历服务付费。
- 价格要和交付物绑定，不按“保证结果”收费。
- 不承诺 offer、面试机会、ATS 通过率、平台审核通过或固定收入。
- 学生用户优先低门槛，复杂定制再提高价格。

## 推荐冷启动路径

```text
免费开源内容 -> 9-29 元快诊 -> 29-69 元单段改写 -> 99 元以上完整带读
```

冷启动时不要一上来推高价。先用低价快诊积累真实案例、反馈和口碑，再把高频问题整理回仓库。

## 成交前确认

收费前至少确认：

```text
1. 用户目标岗位和期望交付物
2. 材料是否已脱敏
3. 是否需要私密处理
4. 能否接受“只基于事实，不编经历”
5. 是否接受不承诺 offer、面试机会和平台结果
6. 修改轮次和截止时间
```

## 修改与退款边界

建议一开始就说清楚：

- 快诊类：通常不含反复修改，只给诊断和下一步建议。
- 单段改写：可包含 1 次基于事实补充后的微调。
- 完整带读：可包含 1-2 次结构调整，但不无限改稿。
- 如果用户要求编造经历、伪造数据、包装虚假证书，应直接拒绝。
- 如果用户提供的信息不足，先追问；追问后仍无事实支撑，就降级表达或建议删除。

## 可复制付款前说明

```text
我可以帮你把简历经历拆成真实、可追问、HR 能看懂的证据链，但不会编造经历、奖项、数据或证书，也不承诺 offer 或 ATS 通过。

如果你接受这个边界，可以先发脱敏材料和目标岗位。我会先判断适合做快诊、单段改写还是完整带读，再确认价格和交付物。
```

## 与平台产品的关系

GitHub 是公开信任入口，Coze 等平台适合做低门槛自动化产品，人工服务适合处理复杂、隐私、需要追问的场景。

不要把三者混在一起收费：

- GitHub：免费方法论、模板、案例、赞赏。
- Coze：自动化技能使用费或平台内付费。
- 人工服务：深度诊断、私密带读、平台上架协助。
