# Services

这个页面用于把开源项目转成可交付服务。开源内容仍然免费可用；付费服务只面向需要更深追问、私密带读、平台上架协助或定制 Skill 的用户。

建议价格和成交边界见 [Suggested Pricing](pricing.md)。

## 服务原则

- 只基于真实经历改写，不编造经历、奖项、排名、证书或项目结果。
- 优先处理面试追问风险，再提升表达密度。
- 可公开讨论的问题请先脱敏后走 GitHub issue。
- 涉及完整简历、联系方式、学校细节、公司资料的内容，不要发到公开 issue。
- 不承诺 offer、ATS 通过率、平台审核通过或固定收入。

## 服务菜单

| 服务 | 适合对象 | 交付物 | 公开/私密 |
| --- | --- | --- | --- |
| 脱敏简历诊断 | 已有简历但不知道问题在哪 | 六维评分、关键词映射、风险清单、修改计划 | 可公开脱敏 |
| 单段经历改写 | 有一段项目/活动写得虚 | 证据单元、保守版/标准版/高密度版、面试追问 | 可公开脱敏 |
| 低素材学生挖掘 | 没实习、没竞赛、没项目 | 可写素材表、企业价值翻译、简历骨架 | 可公开脱敏 |
| 完整简历带读 | 需要逐段追问和重构 | 结构建议、逐段风险、改写方向、最终检查清单 | 建议私密 |
| Coze / Skill 上架协助 | 想把方法论做成技能商店产品 | 技能描述、案例脚本、测试 prompts、上架检查 | 可公开或私密 |
| 团队/社群模板定制 | 班级、社群、训练营、就业服务 | 定制模板、评分表、案例库、使用 SOP | 建议私密 |

## 公开 issue 适合提交什么

使用 [匿名简历诊断 / 服务咨询](../.github/ISSUE_TEMPLATE/resume-diagnosis-request.md) 模板提交：

- 一段已经脱敏的经历。
- 一个简历表达是否有风险。
- 一个普通经历能不能写进简历。
- Skill / Coze 上架材料怎么组织。

公开 issue 不适合提交：

- 完整未脱敏简历。
- 手机号、邮箱、微信号、身份证、家庭住址。
- 成绩单、合同、公司内部文件。
- 面试邀约截图、录用通知、薪资细节。

## 付费前需要准备的信息

为了减少来回沟通，先准备：

```text
1. 目标岗位 / 行业 / 城市
2. 当前简历或经历片段（先脱敏）
3. 你最担心的问题：没东西写 / 写得虚 / 面试答不上 / 不知道投什么
4. 你真实做过的动作、工具、结果
5. 哪些内容不能公开
```

## 交付边界

会做：

- 把经历拆成“动作 + 工具/方法 + 结果”。
- 区分主导、独立完成、参与协助。
- 标出面试追问风险和降级条件。
- 帮你找到低素材经历里的企业价值。
- 整理扣子技能商店上架文案和案例脚本。

不会做：

- 编造经历或数据。
- 把参与写成主导。
- 伪造证书、排名、奖项。
- 承诺投递结果。
- 处理未经授权的他人简历或公司内部资料。

## 推荐路径

```text
公开脱敏 issue -> 小范围诊断 -> 如需深度带读再转私密服务 -> 形成可匿名公开的 Before/After 案例
```

这样既能保护隐私，也能让项目持续积累案例库。
