# 简历压力测试清单

## 1. 识别度

- [ ] HR 看完前 1/3，能判断我适合什么方向。
- [ ] 求职意向和第一段核心经历互相呼应。
- [ ] 简历里有一句能让人记住我的识别标签。

## 2. 证据密度

- [ ] 每条经历都包含动作、工具/方法、结果中的至少两个。
- [ ] 最重要的经历有真实数字、交付物或前后变化。
- [ ] 没有把“在场”写成“负责”，没有把“协助”写成“主导”。

## 3. 可追问性

- [ ] 简历里的每个工具名，我都能讲出真实使用场景。
- [ ] 简历里的每个数字，我都能解释来源。
- [ ] 简历里的每个项目，我都能讲出背景、动作、问题和结果。

## 4. 语言洁净度

- [ ] 删除了“锻炼了能力”“学习了知识”“有一定了解”等空话。
- [ ] 删除了“具备较强能力”“积极主动”“认真负责”等无证据评价。
- [ ] 每句话都比 AI 默认生成的套话更具体。

## 5. 视觉结构

- [ ] 每条经历控制在 2-3 行。
- [ ] 经历超过 4 条时已经分类。
- [ ] 最硬核、最能讲清楚的内容在黄金位。
- [ ] 版面没有大段文字墙。
