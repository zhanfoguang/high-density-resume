## Summary

High Density Resume is a cross-agent `SKILL.md` package for turning raw personal experience into evidence-backed resume content.

## Included

- Core `SKILL.md` workflow.
- User-entry workflow routing.
- HR/ATS screening and enterprise-value guidance.
- Method reference.
- Before / After rewrite patterns.
- Optional dual-AI review workflow.
- Distinctive-signal retention guidance.
- Resume and evidence-unit templates.
- Interactive evidence-unit builder script.
- Generic marketplace manifest.
- Chinese and English listing copy.
- Marketplace test prompts.

## Requirements

- Python 3.10 or later for the helper script.
- A `SKILL.md`-compatible agent for agent usage.

## Privacy

Runs locally and does not require network access.
