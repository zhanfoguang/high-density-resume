# High Density Resume

## 一句话介绍

用证据链写简历，把零散经历改写成可验证、可追问、能体现个人识别度的高密度简历表达。

## 适用人群

- 学生、实习求职者、转专业求职者。
- 大一、大二或项目经历少、觉得自己“没东西可写”的用户。
- 工程、技术、产品、运营、商业实践类候选人。
- 做过事情但不知道怎么挖亮点的人。
- 想避免 AI 套话简历、写出真实细节的人。

## 核心能力

- 将原始经历拆成“动作 + 工具/方法 + 结果”的证据单元。
- 从课程、社团、微任务、帮助他人、AI 辅助学习和非典型技能中挖掘真实简历素材。
- 支持入口分流：从零采矿、单段经历拆解、已有简历审查与重构、多模型交叉审稿。
- 区分主导、独立完成、参与协助，避免夸大经历。
- 构建“专业底盘 + 工具能力 + 独特习惯/背景”的个人识别标签。
- 检查 HR/ATS 关键词分布、保守模板结构和候选人对企业的岗位价值。
- 将模糊表达改写成能经得起面试追问的简历 bullet。
- 支持双 AI 交叉审稿流程：一个模型写，另一个模型审，用户把关真实性、个人识别度、求职方向、HR 搜索率和面试风险。
- 能判断“不直接相关但有识别度”的经历是否值得低优先级保留，例如能证明社交信任、助人倾向、团队融入、服务意识或稀缺记忆点的真实经历。
- 提供简历模板、证据单元表、Before / After 案例和压力测试清单。

## 使用方式

安装 Skill 后，可以这样向 agent 提问：

```text
Use $high-density-resume 帮我把下面这段经历改写成简历表达，并标出哪些地方需要继续追问。
```

也可以运行本地工具：

```bash
python3 scripts/evidence_builder.py --lang zh --output evidence.md
```

## 亮点

- 不编造事实，不替用户夸大经历。
- 支持中文和英文简历。
- 无第三方依赖，不需要服务器。
- 适配 Claude Code、Codex、OpenClaw 风格 agent，以及其他支持 `SKILL.md` 的工具。

## 隐私说明

本 Skill 在用户本地运行，不需要网络请求，不存储用户简历数据。用户应避免输入未经脱敏的敏感信息。
