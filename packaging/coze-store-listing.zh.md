## 详细介绍

```text
简历证据链是一款面向大学生、实习求职者、转行者的高密度简历优化技能。

很多人不是没有经历，而是不知道哪些经历有价值。尤其是大学生，可能没有大厂实习、没有高含金量竞赛、没有完整项目，但仍然在课程实验、社团活动、团队协作、技能学习、帮助他人、解决小问题的过程中积累了真实能力。

本技能不会一上来套模板，也不会把经历写虚。它会先判断你的输入类型，再选择追问、诊断、改写或风险检查流程，把经历拆成“动作 + 工具/方法 + 结果”的证据链。

核心能力：
1. 从零挖掘简历素材：从目标岗位、专业课程、实训作业、社团任务、工具使用、证书、作品、团队角色和日常经历中追问。
2. 低素材学生挖掘：帮助没实习、没竞赛、没项目的学生，从课程、微任务、帮助他人、AI 辅助学习和非典型技能中找到可写证据。
3. 单段经历改写：把“参加过活动”“负责过一些工作”“学习过某项技能”改写为更具体的简历表达。
4. 已有简历审查：从真实性、个人识别度、求职方向匹配、HR 搜索率、面试可追问性、结构扫读性六个维度诊断。
5. 面试风险检查：标出哪些词可能被 HR 或技术面试官追问，哪些内容如果答不上来就应该降级、补证据或删除。
6. 其他 AI 建议审查：逐条判断采纳、驳回、部分采纳或需补事实，避免把简历改得更虚、更模板化。

使用方法：
你可以直接发送目标岗位、零散经历、已有简历、某段项目描述，或另一个 AI 给出的修改建议。技能会先判断场景，再输出追问清单、证据单元、改写版本或风险清单。

注意事项：
本技能坚持真实性优先，不会把“参与”写成“主导”，不会把“基于模板修改”写成“独立原创设计”，不会添加无法解释的数据、排名、奖项或能力标签。对于中医针灸等健康相关经历，只作为个人技能、服务意识、团队融入和信任建立信号表达，不提供医疗承诺或治疗效果宣传。
```

## 推荐开场白

## 3 个上架案例

扣子要求案例真实、可访问、不重复，并展示完整交互过程。每个案例都要跑到最终交付，不要只跑到追问中途。

### 案例 1：低素材大学生简历挖掘

案例标题：

```text
没实习没竞赛，怎么挖出可写简历素材
```

用户 Query：

```text
我大一，没实习没竞赛，也没什么项目。平时参加社团活动，帮老师和同学处理过一些小事，会一点 Excel，也学过中医针灸基础，偶尔帮同学做基础放松。目标还不确定，可能想找办公室助理、运营助理或者普通实习。帮我看看简历能写什么。
```

案例应展示：

- 技能识别为“低素材挖掘”。
- 追问课程作业、社团任务、帮助对象、Excel 使用场景、目标岗位方向。
- 把小经历翻译成执行可靠、降低沟通成本、团队信任、服务意识和稀缺记忆点。
- 对中医针灸只做保守表达，不写治疗、治愈、诊断。

最终交付应包含：

```text
已有信息 / 缺失事实 / 可写方向表
低素材证据单元表
可放入简历的保守表达
下一轮追问清单
```

标题：低素材学生也能挖出证据链

### 案例 2：方程式赛车经历高密度改写

案例标题：

```text
把“参与赛车电器工作”改成可追问项目经历
```

用户 Query：

```text
我参加过方程式赛车队，做过电器相关工作，也用 AI 帮队里抢车号。PCB 是基于参考模板改的，抢车号一开始成绩不太好，后来我调整了一下整理规则的方法，结果排名变好了。帮我写进简历。
```

案例应展示：

- 技能追问是否主导、独立完成或参与协助。
- 追问 PCB 实际改了什么、用什么工具、是否打样/焊接/测试。
- 追问抢车号前后排名、总队伍数、AI 工具具体用法、策略是不是用户自己判断。
- 在信息不足时先给保守版，不直接写“主导整车电气系统设计”。

最终交付应包含：

```text
证据单元
缺失事实
保守版 / 标准版 / 高密度版
面试追问风险
```

配图建议：

```text
标题：动作 + 工具/方法 + 结果
画面：普通表述 -> 高密度表达 -> 面试追问检查
可用占位封面：assets/coze-case-formula-student.svg
```

### 案例 3：审查另一个 AI 的修改建议

案例标题：

```text
别让 AI 把简历改虚：逐条审查修改建议
```

用户 Query：

```text
这是另一个 AI 对我简历提出的修改建议，请你不要全盘采纳，而是按采纳、驳回、部分采纳、需补事实分类：
1. 删除中医针灸经历，因为它和智能制造无关。
2. 把“参与方程式赛车电器工作”改成“主导整车电气系统设计”。
3. 把“CodeX 整理赛事规则”改成“熟练掌握 AI 工具并显著提升团队成绩”。
4. 求职意向缩短为“智能制造实习生”。
5. 把抢车号排名从“第 19 名”保留为精确数字，并补充前后变化。
```

案例应展示：

- 驳回“参与”改“主导”。
- 驳回没有证据的“熟练掌握”和“显著提升”。
- 部分保留中医针灸，但移动到低优先级区域并改成团队融入/助人信号。
- 采纳精确排名，但要求补充前后变化和排名背景。

最终交付应包含：

```text
逐条裁决表
面试追问场景
需补事实清单
可采纳的安全写法
```

配图建议：

```text
标题：采纳 / 驳回 / 部分采纳 / 需补事实
画面：AI 建议审查表 + 红色风险项
可用占位封面：assets/coze-case-ai-review.svg
```

## 付费设置建议

上架初期建议先用低门槛策略验证需求：

| 阶段 | 建议 |
| --- | --- |
| 冷启动 | 免费或低价，先积累案例、评价和真实反馈 |
| 有稳定案例后 | 设置一次性付费或订阅，突出“低素材挖掘 + 面试风险检查”的差异 |
| 有私域流量后 | GitHub / 社群 / 朋友圈引流到扣子技能，再承接一对一简历诊断 |

不要承诺：

- 保证拿 offer。
- 保证通过 ATS。
- 保证平台审核通过。
- 保证上架后一定产生收入。
